# Kaggle Classic

![New Kaggle logo to classic Kaggle logo](assets/readme-banner.svg)

Make Kaggle classic again!

Restore classic colors, fonts, buttons, sidebar, medals, and avatar rings on Kaggle.

## Install in Chrome

1. Download the ZIP and extract it, or clone the repository.
2. Open `chrome://extensions`.
3. Turn on Developer mode, then click **Load unpacked**.
4. Select the folder containing `manifest.json`, then refresh Kaggle.

Use On/Off in the extension popup to toggle classic styling. No build step is needed. Your setting is stored locally in Chrome.
